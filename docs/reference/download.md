# Download

Download NX Redux, point it to your ROMs folder, and start playing. Supported
emulators are built in - no RetroArch tinkering, no extra apps, no ads, and no
account required.

## Handheld (TrimUI)

Custom firmware for the TrimUI Brick, Brick Hammer, Brick Pro, Smart Pro S
and Smart Pro. Runs from your microSD card with 41 systems built in - your stock
OS stays safe. Releases are packaged per device, so download the zip for
**your exact model**, then follow
[Getting Started](../handheld/getting-started.md) to install it.

<div class="nx-badges" markdown>
[:fontawesome-brands-github: Download Latest Release on GitHub](https://github.com/nx-redux/nx-handheld/releases/latest){ .nx-badge-link }
</div>

After first boot, updates install over Wi-Fi from **Settings → About**.

## Android (Mobile & Handhelds)

Self-contained app for Android 8.0 or later (arm64) phones, tablets, foldables,
and Android handhelds - with all 39 systems baked straight into the APK. Download
the APK, then follow
[Getting Started on Mobile](../mobile/getting-started.md#install) to install
it.
